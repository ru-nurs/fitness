# SportShopFitness

Node.js/Express MVP для `sportshopfitness.ru` по ТЗ от 25 мая 2026: маркетплейс товаров, услуг, курсов и инструментов для фитнес-тренеров.

В текущем прототипе есть:

- главная страница маркетплейса;
- каталог с поиском, фильтрами и сортировкой;
- карточки товаров, курсов, услуг, сертификатов и бандлов;
- демо-покупка с записью заказа;
- кабинет покупателя с заказами, материалами и подписками;
- кабинет тренера-продавца с витриной, заказами, рефералкой, балансом и заявкой на вывод;
- админка для модерации товаров, просмотра заказов, заявок и статуса Яндекс.Маркет FBS / DBS;
- демо-данные под платформу, а не старую CRM-only концепцию.

## Запуск

```bash
npm install
npm start
```

Сайт будет доступен на `http://localhost:3000`.

## Демо-доступы

| Роль | Email | Пароль |
| --- | --- | --- |
| Тренер | `trainer@sportshopfitness.local` | `password123` |
| Клиент | `client@sportshopfitness.local` | `password123` |
| Админ | `admin@sportshopfitness.local` | `password123` |

Данные хранятся в PostgreSQL, если задан `DATABASE_URL`, или в `data/db.json` как fallback без базы.

## PostgreSQL

Приложение использует `DATABASE_URL` из `.env`. При старте оно создает таблицу `app_state` в PostgreSQL/Supabase и хранит там текущее состояние MVP в JSONB.

Для другой базы достаточно поменять `DATABASE_URL` и при необходимости `APP_STATE_KEY`.
